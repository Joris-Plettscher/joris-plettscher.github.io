Computational Psychiatry Synthesis

Which hidden mechanism produces this person's data, and can it be told apart from the alternatives?
Starting problem: one diagnosis (a spectrum disease) can rest on different mechanisms, and symptoms alone cannot say which.

AnalogyFever is one sign with many causes; the thermometer reading alone cannot choose the treatment.Where it breaks down: the causes of fever are known and testable. Here the candidate mechanisms are themselves hypotheses that must first be formalised as models.

Checks on a model

CheckQuestionDataFitted withOutputFailure means
Parameter recoveryCan I find the true parameters?Simulated, known parametersThe same modelSimulated vs recovered; parameter correlationsBug, weak design, or parameters trade off
Model recoveryCan my comparison tell the models apart?Simulated from every modelEvery modelConfusion matrix → inversion matrixA "winning model" on real data says little
Model comparisonWhich candidate explains the real data best?RealEvery modelEvidence, BIC, exceedance probabilityOnly relative: best of those tested
ValidationCan the winner produce the behaviour?Simulated from the winner with fitted parameters— (compared with real data)Model-independent signatures reproduced or notModel misses the mechanism → revise model or task

Recovery checks run on simulated data and ask whether the method can work at all; comparison and validation run on real data and ask whether it did.

AnalogyModel recovery is like validating a diagnostic test on cases with known diagnoses before using it on patients; the confusion matrix plays the role of sensitivity and specificity.Where it breaks down: the known cases are generated by the models themselves, so the result is a best case. Real behaviour is produced by none of the candidate models exactly.
